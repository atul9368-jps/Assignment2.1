Step 1 & 2: Create index.html with Basic Structure
Open your code editor (like VS Code, Notepad++, or TextEdit) and create a new file named index.html.

Add the standard HTML5 boilerplate structure (<!DOCTYPE html>, html, head, and body).

Step 3, 4 & 5: Add Title, Headings, Comments, and Proper Indentation
Copy and paste the following code into your index.html file. Notice how it includes the required title, one main heading (<h1>), three subheadings (<h2>), HTML comments (<!-- ... -->), and clean indentation:

HTML
<!DOCTYPE html>
<html lang="en">
<head>
    <!-- Set the character encoding and page title -->
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My First Webpage</title>
</head>
<body>

    <!-- Main Heading of the page -->
    <h1>Welcome to My First Webpage</h1>

    <!-- Subheadings -->
    <h2>About Me</h2>
    <h2>My Hobbies</h2>
    <h2>Contact Information</h2>

</body>
</html>
Save the file.

Step 6: Verify by Opening in a Browser
Find your index.html file on your computer.

Double-click the file (or right-click and choose Open with -> select any web browser like Chrome, Edge, or Firefox).

Verify that your tab displays the title "My First Webpage" and that you see your main heading and three subheadings on the screen.
